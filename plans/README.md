- Add a bundler / code-split Three: global constraint. Vendor JS is large but settled.
- Cache-Control on `serve.py`: by design (`no-store` because module imports have no `?v=`). Production static hosts already cache.
- Reuse globe.gl pin DOM across `setPlaces`: one-shot on tab/space change; globe.gl owns `htmlElementsData`. Not the first lever.
- Strip CSS star twinkles / Luna drop-shadow: that is the look. Budget on phones later; do not start by deleting character.
- Rebuild globe.gl or run two live Threes: forbidden. Plan 003 pauses the outgoing scene; it does not add a second engine.
- Merge camera `tweenCamera` rAF into `animate()`: real, smaller than 003; defer unless 003 still leaves competing loops after pause is correct.
